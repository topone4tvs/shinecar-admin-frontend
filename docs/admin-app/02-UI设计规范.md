# 02 · UI 设计规范

> 适用于「焕车掌柜」管理端小程序。所有数值以 **750rpx 设计宽度** 标注，括号内为 375pt 对照值。
> 可直接落地的变量见 [`tokens.scss`](./tokens.scss)；可点原型见 [`../admin-app-ui-demo.html`](../admin-app-ui-demo.html)。

---

## 1. 设计原则

| 原则 | 含义 | 落地判断 |
|---|---|---|
| **现场优先** | 站着单手操作，一眼看清状态 | 关键信息（状态 / 时长 / 车牌 / 金额）在首屏直出，不藏在详情里 |
| **状态即颜色** | 颜色只表达状态，不做装饰 | 绿=空闲、橙=使用中、玫红=维护中；品牌色不用于「成功」 |
| **危险要显眼** | 不可逆操作必须视觉降速 | 红色描边卡 + 红色确认按钮 + 影响面文案，不做长按/滑动 |
| **密度克制** | 信息密但不挤 | 卡片内不套卡片超过两层；一屏最多 2 个视觉层级强调（大数字 + 主按钮） |
| **不发明新控件** | 全站只有 5 类交互容器 | 卡片、弹层 Sheet、确认 Dialog、Toast、整页跳转 |

---

## 2. 画布与单位

| 项 | 值 |
|---|---|
| 设计宽度 | 750rpx（= 375pt = iPhone 6/7/8 逻辑宽度） |
| 换算 | **1px（设计稿 375pt）= 2rpx**；1pt = 2rpx |
| 页面左右安全边距 | 32rpx |
| 最小点击区 | 88×88rpx（视觉可小，热区补足） |
| 栅格 | 4rpx 基准；常用间距 8 / 16 / 24 / 32rpx |
| 内容最大宽度 | 不限制（小程序全屏） |

> 代码中一律写 `rpx`，不写 `px`。1px 边框写 `2rpx`（部分机型 1rpx 会消失）。

### 3.1 品牌与中性

| Token | 色值 | 用途 | 不要用在哪 |
|---|---|---|---|
| `--brand` | `#E6436E` | 主按钮、选中态、Tabbar 激活、强调数字 | 成功提示、价格涨跌 |
| `--brand-press` | `#D33A61` | 主按钮按压态 | — |
| `--brand-deep` | `#A82750` | 玫红底上的文字（维护中、品牌浅底文字） | 大面积背景 |
| `--brand-soft` | `#FDEBEF` | 维护中底色、选中标签底、品牌浅底 | 正文背景（对比不足） |
| `--brand-line` | `#F3B6C8` | 品牌浅底描边 | 分割线 |
| `--ink` | `#1F2329` | 标题、主要数值 | 次要说明 |
| `--ink-2` | `#6B7280` | 正文、次要按钮文字 | 标题 |
| `--ink-3` | `#9AA1A9` | 说明、时间、单位 | 主要信息 |
| `--ink-4` | `#B9BFC7` | 占位符、禁用文字 | 任何可读正文 |
| `--line` | `#EEF0F2` | 卡片内分割线（0.5px） | 卡片外边框 |
| `--line-2` | `#E4E7EB` | 输入框/幽灵按钮描边 | 分割线 |
| `--bg` | `#F7F8FA` | 页面背景、导航栏背景 | 卡片背景 |
| `--card` | `#FFFFFF` | 卡片、弹层 | 页面背景 |
| `--fill` | `#F4F6F8` | 图标底、输入框底、次要按钮底 | 文字色 |

### 3.2 语义状态色

> 状态色分「浅底（卡片/工位块）」与「标签底（Pill）」两档，**不要混用**。

| 状态 | 浅底（工位块） | 浅底描边 | 文字 | 标签底 | 标签文字 |
|---|---|---|---|---|---|
| 空闲 | `#EAF7E2` | `#CBE9B8` | `#2F7A12` | `#F3FBEE` | `#2F7A12` |
| 使用中 | `#FFF6E2` | `#F5DFB0` | `#8F5E00` | `#FFF9EC` | `#8F5E00` |
| 维护中 | `#FDEBEF` | `#F3B6C8` | `#A82750` | `#FDEBEF` | `#A82750` |
| 已下线/停用 | `#F2F4F6` | `#E4E7EB` | `#6B7280` | `#F2F4F6` | `#6B7280` |
| 危险/失败 | `#FEF1F0` | `#F6C9C5` | `#B3241C` | `#FEF1F0` | `#B3241C` |

- 辅助绿（图标底）：`#EAF3E5` / `#2F7A12`；通风青：`#E8F5F2` / `#0F7B6C`。
- 维护中**必须用品牌玫红**，不要用纯红 `#FF1100`，避免与「危险」语义打架。

### 3.3 使用禁令

1. 页面背景不要用纯白，卡片才会「浮」起来。
2. 同一屏内不超过 2 处品牌色实心块（主按钮 + 1 个强调）。
3. 不用颜色单独表意：状态必须「颜色 + 圆点 + 文字」三件套。
4. 不使用渐变做背景色（仅计时 Hero 卡允许 135° 双色渐变，且同色系）。
5. 不使用阴影表达层级，除卡片默认阴影与悬浮条/弹层。

## 4. 字体

### 4.1 字族

```
font-family: 'PingFang SC', -apple-system, BlinkMacSystemFont, 'Helvetica Neue', sans-serif;
数字/单号/授权码：ui-monospace, SFMono-Regular, Menlo, monospace（仅授权码、订单号）
```

### 4.2 字号阶梯

| Token | rpx | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `display` | 70 | 600 | 1.1 | 工位详情计时主数字 |
| `metric` | 62 | 600 | 1.1 | 大号数字（预留：停车待缴金额，本期无金额展示） |
| `h1` | 42 | 600 | 1.15 | 状态汇总数字 |
| `h2` | 40 | 600 | 1.3 | 登录页主标题 |
| `h3` | 34 | 600 | 1.3 | 工位号、用户昵称、订单金额、车位号 |
| `h4` | 32 | 600 | 1.4 | 导航标题、弹层标题、Dialog 标题 |
| `title` | 28 | 600 | 1.4 | 卡片标题、主按钮文字 |
| `body` | 26 | 400/500 | 1.6 | 正文、KV 值、列表主文 |
| `body-sm` | 25 | 400 | 1.6 | 次要正文、订单卡 KV |
| `caption` | 23 | 400 | 1.6 | 辅助说明、时间戳 |
| `caption-sm` | 22 | 400 | 1.65 | 提示、脚注、空态说明 |
| `micro` | 21 | 500 | 1.4 | 标签、状态文字、按钮副标 |
| `nano` | 19 | 500 | 1.4 | 角色标签、角标 |

**规则**
- 一屏内字号不超过 5 档；标题与正文至少差 4rpx 才拉开层级。
- 金额与时长统一 `font-weight: 600` + `font-variant-numeric: tabular-nums`（等宽数字，防跳动）。
- 中文不使用 `letter-spacing` 为负值；仅英文/数字大标题允许 `-0.5rpx ~ -2rpx`。
- 单行标题超长省略：`overflow:hidden; text-overflow:ellipsis; white-space:nowrap`。

## 5. 间距 / 圆角 / 描边 / 阴影

### 5.1 间距

| Token | rpx | 典型用途 |
|---|---|---|
| `sp-1` | 8 | 图标与文字、标签内左右 |
| `sp-2` | 16 | 卡片间、网格 gap、按钮间距 |
| `sp-3` | 24 | 卡片下外边距、区块间距 |
| `sp-4` | 32 | 页面左右边距、弹层左右边距 |
| `sp-5` | 40 | 弹层底部、按钮上下 |
| `sp-6` | 48 | 区块之间大留白 |

- 卡片内 padding：**28rpx**（14px）；紧凑卡（工位块）20/22rpx。
- 卡片之间 margin-bottom：**24rpx**；连续卡片不合并阴影。

### 5.2 圆角

| Token | rpx | 用途 |
|---|---|---|
| `r-xs` | 8 | 极小标签（角色） |
| `r-sm` | 12 | Pill、小标签 |
| `r-md` | 16 | chip、小按钮 |
| `r-lg` | 20 | 主按钮、输入框、图标底 |
| `r-xl` | 24 | 工位块、操作块 |
| `r-2xl` | 28 | 卡片 |
| `r-3xl` | 32 | 计时 Hero、Dialog |
| `r-sheet` | 36 | 底部弹层顶部圆角 |
| `r-full` | 999 | 胶囊按钮、头像、悬浮条 |

### 5.3 描边

| 场景 | 值 |
|---|---|
| 卡片分割线 | `1rpx solid #EEF0F2`（用 `.5px` 亦可） |
| 输入框 / 幽灵按钮 | `2rpx solid #E4E7EB` |
| 状态块 | `2rpx solid` 对应浅底描边 |
| 虚线（车牌未填写、占位区） | `2rpx dashed #D6DBE2` |

### 5.4 阴影

| 场景 | 值 |
|---|---|
| 卡片 | `0 2rpx 8rpx rgba(23,35,61,.05)` |
| 悬浮切店条 | `0 16rpx 44rpx rgba(23,35,61,.12)` |
| 底部弹层 | `0 -16rpx 52rpx rgba(23,35,61,.12)` |
| Toast | `0 8rpx 24rpx rgba(0,0,0,.18)` |
| 遮罩 | `rgba(20,24,30,.42)` |

> 阴影方向统一「向下」，弹层特殊为向上；不要用内阴影。

## 6. 图标

### 6.1 字符图标（默认方案）

管理端功能词都是单字动词/名词，采用**汉字字符图标**，零资源、无需切图、辨识度高。

| 项 | 规格 |
|---|---|
| 容器 | 64×64rpx，圆角 20rpx |
| 字号 | 28rpx，字重 600 |
| 默认 | 底 `#F4F6F8`，字 `#4B5563` |
| 品牌强调 | 底 `#FDEBEF`，字 `#A82750` |
| 成功/设备 | 底 `#EAF3E5`，字 `#2F7A12` |
| 通风 | 底 `#E8F5F2`，字 `#0F7B6C` |
| 危险 | 底 `#FADCD9`，字 `#D93026` |
| 取字规则 | 取功能首字或核心字：开 / 播 / 停 / 维 / 风 / 巾 / 柜 / 查 / 审 / 缴 |

**`icon` 枚举 → 字形映射**（能力配置下发的是英文 key，前端只认 key，不认中文字段）：

| `icon` key | 字 | 默认底/字色 | 典型能力 |
|---|---|---|---|
| `door` | 开 | `#FDEBEF` / `#A82750` | 开门 |
| `voice` | 播 | `#F4F6F8` / `#4B5563` | 语音播报 |
| `stop` | 停 | `#FADCD9` / `#D93026` | 结束订单 |
| `wrench` | 维 | `#F4F6F8` / `#4B5563` | 设为维护 |
| `fan` | 风 | `#E8F5F2` / `#0F7B6C` | 通风 |
| `cabinet` | 巾 | `#EAF3E5` / `#2F7A12` | 毛巾柜（预留） |
| `park` | 缴 | `#EAF3E5` / `#2F7A12` | 停车缴费 |
| `coin` | 充 | `#FFF6E2` / `#8F5E00` | 资产 / 充值类 |

> 未收录的 key 走兜底：底 `--fill`、字 `--ink-3`，取 `title` 首字。新增设备只需在前端补一行映射，不改组件。
> 注意 `stop` 用「停」、`park` 用「缴」，避免同页出现两个「停」。

> 同一页面内字符图标不超过 8 个，且必须两两不同字，避免混淆。
> 若后续统一改为线性图标：24×24pt、`stroke-width: 1.6`、`round` 端头，尺寸 44rpx，其余规范不变。

### 6.2 Tabbar 图标

线性图标 42×42rpx，`stroke-width: 1.6`，颜色跟随 `currentColor`；激活 `--brand`，未激活 `#9AA1A9`。

## 10. 适配与安全区

1. **底部安全区**：所有固定底栏（Tabbar、底部按钮条、悬浮条）加 `padding-bottom: env(safe-area-inset-bottom)`。
2. **顶部安全区**：使用自定义导航时，`padding-top` 取状态栏高度（`wx.getWindowInfo().statusBarHeight`）；本期建议用系统导航栏，减少适配成本。
3. **小屏（iPhone SE 375×667）**：工位网格保持 2 列；弹层最大高降到 88%，内容区可滚动。
4. **大屏 / 折叠屏**：内容区最大宽 750rpx，居中，两侧留白用页面背景填充。
5. **横屏**：不强制，页面锁定竖屏（`pageOrientation: portrait`）。
6. **字体缩放**：不禁止系统字号缩放，但关键数字（计时、金额）用固定 `rpx` 避免撑破卡片。

| 点击热区 | ≥ 88×88rpx；mini-btn 视觉 40rpx 但外层热区补足 |
| 状态表达 | 颜色 + 圆点 + 文字，三重冗余 |
| 危险确认 | 文案说明「影响谁、能不能撤回」，不只写「确定吗」 |
| 单手可达 | 主操作集中在屏幕下半部（底部按钮条 / 2×2 网格） |
| 误触防护 | 破坏性操作不与常用操作相邻；不给「结束订单」放主位 |
| 加载反馈 | 任何 >300ms 的操作必须有 loading；>1.5s 加文案「正在下发指令」 |

## 13. 代码落地约定

1. **变量来源唯一**：所有颜色/字号/圆角从 `tokens.scss` 引用，禁止页面内写十六进制色值。
2. 全局注入：Taro `sass.resource` 引入 `tokens.scss`，页面直接 `@include` 或 `@use`。
3. 类名 BEM：`.block__element--modifier`（如 `.station__idx`、`.act--danger`）。
4. 单位：只写 `rpx`；`1rpx` 边框改 `2rpx`。
5. 组件样式不写死宽度，用 `flex` / `grid`；网格列数由配置驱动（柜门 `columns`）。
6. JS 侧需要颜色时（Canvas、图表、动态渐变）从 `utils/theme.ts` 读取，与 `tokens.scss` 手动保持同步，改动需同时改两处并记在 PR 描述里。
