# 首个超管账号（seed）

> 后端 `cmd/adminctl` 尚未实现（P0a 交付物之一），本文件先固定联调用的 seed 参数，避免实现时再问一遍。

| 字段 | 值 | 说明 |
|---|---|---|
| 姓名 | 超级管理员 | 占位，可在「我的」页改 |
| 手机号 | 13800138000 | **占位测试号**，上线前替换为真实负责人号码 |
| 角色 | `super` | 全局作用域，可见全部门店 |
| 绑定授权码 | 8 位，由 `adminctl` 生成 | 建议首版从环境变量 `ADMIN_INIT_CODE` 注入，便于联调 |
| 微信 openid | 首次 `auth/bind` 时写入 | 超管本人在小程序里输手机号 + 授权码完成绑定 |

## 约束

- 手机号只作账号标识，**不做短信验证**；授权码由管理员线下发放（提审备注里要写清）。
- 授权码只存哈希，`code_used_at` 记录使用时间；一次绑定后失效。
- 上线前 `update admin_accounts set phone='<真实号码>'` 或用 `adminctl` 重建，禁止把占位号码带到生产。
